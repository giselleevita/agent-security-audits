# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include the affected file or check, the steps to reproduce, and what you expected to happen. You can expect an acknowledgement and an initial assessment; response times are best effort.

## Scope

This repository re-runs checks against published AI-agent security claims. Findings about the claims themselves are welcome as issues. Problems in the scripts that could mislead a reader are security-relevant and should be reported privately first.
